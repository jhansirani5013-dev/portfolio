# Resume

Place your resume PDF file here as `Jhansi_Rani_Resume.pdf` to enable the resume download functionality.

The resume button in the navigation and hero section will link to `/resume/Jhansi_Rani_Resume.pdf`.

If no resume file is present, the button will attempt to open the path but will show a 404 error. Consider removing or disabling the resume button if you do not have a PDF ready.
